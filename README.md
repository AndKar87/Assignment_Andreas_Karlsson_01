# Assigment - Andreas Karlsson - 3D Engineer

Since I had no prior experience with WebGL and not much with javascript in general I took the opportunity to gain some.

I diverged from the assignment and decided to make everything from the ground up, including reading .glb files, no 3rd party libraries. I also made the test model.

I've spent about 12 days on this, with a soft start at the 1st of January. The code base became quite big, even after cleanup. I'm sorry for any inconvenience that may cause.

# Usage Instructions
Just open index.html. The glb file is loaded using the Fetch API so it has to run on a server. You can also run it from my own domain. Use the link below.

[Link](https://unlitart.com/Other/Assignment_Andreas_Karlsson_01)

# Notes
1. The shader code is incorporated into the html. I used my own static site generator to automate the process. You can find the separate sources in *Shaders/*. I went this route merely because it was the most reliable solution I could find.\
On a side note, the shader code was also generated by another parser of mine which supports `#include` statements.
2. I don't use GitHub so there is no git history of this project. I can however provide local backups from each day if required.
3. I didn't use TypeScript since I'm not using any IDE that would support it.
